15. Role-Based Dashboards
Admin (System-Level)
•	Full system access
•	Manage users, roles, settings
•	Access all research data (including sensitive PII)
Program Admin (Domain-Level)
•	Manage specific program areas
•	Access program-specific data only
•	Approve content within domain
•	PII fields masked where necessary
Researcher
•	Upload/manage transcripts
•	View/analyze research data
•	Submit content for review
Partner
•	View/download assigned reports
•	Read-only access
Subscriber
•	Access published content
•	View public research insights
________________________________________
16. Access Control Rules
•	Admin → Full access
•	Program Admin → Domain-restricted access
•	Researcher → Controlled access
•	Partner → Read-only
•	Subscriber → Public + personal access only
Security Enhancements: least privilege, field-level permissions, PII masking
