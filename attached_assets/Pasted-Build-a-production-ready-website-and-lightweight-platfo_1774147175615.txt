Build a production-ready website and lightweight platform foundation for I.T.S. Fatherhood using a modern TypeScript web stack.

The site must NOT feel like a traditional nonprofit, church flyer, or generic community program website.

This brand must be positioned as a:

“Fatherhood Impact & Intelligence Platform”

It combines research, mentorship, technology, and ecosystem partnerships to measure, track, and improve fatherhood outcomes.

The website must communicate:
- system-level thinking
- measurable impact
- data intelligence
- platform architecture
- category creation
- scalable community deployment

Do NOT default to normal nonprofit language such as:
- “we help fathers”
- “we serve the community”
- “our mission is to support”
- “we provide services”

Instead use language centered on:
- measure
- track
- analyze
- activate
- improve
- scale
- intelligence
- platform
- ecosystem
- outcomes
- infrastructure

==================================================
1. TECH STACK
==================================================

Use:
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui components
- Lucide icons
- Recharts for data visuals
- Prisma ORM
- PostgreSQL database
- Zod for validation

Structure the app so it can start as a public-facing website, but the architecture should support later expansion into:
- survey intake
- partner portal
- research dashboards
- content/resource center
- admin CMS-like content management

==================================================
2. BRAND / POSITIONING RULES
==================================================

The site should present I.T.S. Fatherhood as:
- a platform, not a program
- a model, not just a ministry
- an intelligence engine, not just a support initiative
- a scalable ecosystem, not a collection of events

Core positioning statement:
“I.T.S. Fatherhood is a Fatherhood Impact & Intelligence Platform that measures, tracks, and improves fatherhood outcomes using data, mentorship, and technology.”

Tone:
- credible
- bold
- strategic
- modern
- data-aware
- hopeful without sounding soft
- strong enough for funders, partners, researchers, churches, schools, and fathers

Avoid:
- pity-based framing
- overly sentimental messaging
- generic nonprofit cliches
- stock “community outreach” copy

6. ANIMATION / INTERACTION SYSTEM
==================================================

Use Framer Motion throughout, but tastefully.

Animation style:
- modern
- smooth
- not flashy
- strategic
- premium SaaS feel

Required animation patterns:
- hero text stagger reveal
- fade/slide on scroll for sections
- animated metric counters
- hover lift on cards
- tab transitions
- line-drawing or node-connection animation for ecosystem diagrams
- subtle parallax on hero background shapes
- CTA pulse glow on high-priority buttons
- content filter transitions on insights page

Do not overanimate.
The site should feel intelligent and intentional.

15. COPY GUIDELINES
==================================================

All on-site copy must obey these rules:
- never sound generic
- avoid excessive “support/help/serve” language
- lead with measurable and structural language
- blend conviction with clarity
- sound strategic enough for grantmakers and partners
- still remain understandable to community users

Example copy direction:
Bad:
“We are dedicated to helping fathers and families through meaningful support.”
Good:
“We build systems that measure and improve fatherhood outcomes across families and communities.”

Bad:
“Our programs uplift fathers.”
Good:
“Our platform activates father engagement through research-backed mentorship and measurable intervention models.”

If no, rewrite the copy and visual hierarchy until the answer is yes.

“This is not just a fatherhood program. This is infrastructure for measuring and improving fatherhood outcomes.”
