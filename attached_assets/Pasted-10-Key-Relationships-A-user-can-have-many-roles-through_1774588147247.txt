10. Key Relationships
• A user can have many roles through user_roles.
• A father profile can have many survey responses, assessment results, interviews, transcripts, and program participation
records.
• A transcript can create many NLP jobs; each NLP job can create many outputs.
• A publication can reference tagged themes derived from transcript, survey, and assessment data.
11. Security & Privacy Requirements
• Encrypt all traffic with HTTPS.
• Use role-based access control for protected screens and APIs.
• Store passwords only as secure hashes when passwords are used.
• Use least-privilege access for partners and volunteers.
• Maintain audit logs for login, export, update, and delete actions.
• Support masking or de-identification of sensitive father records where needed.
• Separate public publication content from protected research records.
